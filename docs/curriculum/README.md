# Curriculum Foundation

This directory contains the canonical Android Dojo lesson sequence.

Lessons follow the format defined in `CANON.md` and use the identifier form:

```text
AD-<belt>-<number>
```

The first lesson establishes the evidence-first habit that every later operation depends on.

## Initial sequence

| ID | Belt | Topic | Risk |
|---|---|---|---|
| AD-white-001 | White | Establish a device dossier | SAFE |

A lesson is not complete until its verification and recovery sections are understandable to a beginner.
